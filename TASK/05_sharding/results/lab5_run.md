## Задание 5: добавление 4-го шарда (modulo)

| Метрика | Значение |
|---------|---------:|
| Всего записей | 100 000 |
| Изменили шард (mod 3 -> mod 4) | 76 012 |
| Остались на прежнем шарде | 23 988 |
| **Процент перемещаемых** | **76.01%** |

Modulo меняет делитель 3 -> 4, поэтому почти для всех ключей меняется
остаток: теория предсказывает ~75% перемещений, что и наблюдается.
