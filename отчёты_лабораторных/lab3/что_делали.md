# Лаба 3 — что мы делали

**Тема:** партиционирование больших таблиц + автоматическое создание партиций и алерты.

### Коротко
1. На учебной схеме `lab3` попробовали **RANGE / LIST / HASH**, partition pruning, DEFAULT, индексы на партициях.
2. Таблицу проекта **`adoptions`** разбили по **`created_at`** (RANGE, по месяцам).
3. В коде сервиса: **CreatePartitionsJob** (будущие месяцы), **удаление** старых (retention 24 мес.), **PartitionHealthCheck** + уведомления в `project/alerts/`.
4. Автозапуск: **не cron**, а `BackgroundService` раз в час; также API вручную.
5. Проверили 3 API-запроса: где pruning есть (фильтр по дате) и где нет (`id`, `GROUP BY` без даты).
6. Сымитировали сбой → CRITICAL → восстановление → OK.
