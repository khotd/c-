# Лаба 4 — что мы делали

**Тема:** Read Scaling — Primary + Replica, streaming replication.

### Коротко
1. В Docker подняли **Primary** (`db:5432`) и **Replica** (`db-replica:5433`).
2. Настроили **streaming replication** (WAL → walreceiver).
3. Доказали: INSERT на Primary виден на Replica; INSERT на Replica → read-only error.
4. В backend `GET /api/animals` читает с **ReplicaConnection**; запись остаётся на Primary.
5. Зафиксировали **replication lag** (async, миллисекунды).
