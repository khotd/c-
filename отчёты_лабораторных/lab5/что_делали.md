# Лаба 5 — что мы делали

**Тема:** Шардирование PostgreSQL — Router (`hash % N`) и Consistent Hashing.

### Коротко
1. Выбрали сущность **`adoptions`**, shard key — **`user_id`**.
2. Подняли **3 независимых PostgreSQL** (`shelter_shard0/1/2`, порты 5445–5447,
   compose: `project/docker-compose.shards.yml`, +4-й шард через `--profile four`).
3. Реализовали **Router** (`TASK/05_sharding/scripts/shard_router.py`):
   `hash(md5(user_id)) % N` и Consistent Hash Ring (100 vnodes); те же хеши —
   в SQL (`sql/02_router_functions.sql`).
4. Сгенерировали и физически загрузили **100 000 записей `adoptions`** в шарды
   обеими стратегиями (БД `shelter_shard` — modulo, `shelter_ring` — кольцо).
5. Сравнили перемещение при **3 → 4 шарда**: modulo **76.01%**, кольцо **27.81%**.
6. Сверили SQL-расчёт с Python: 25 996 + 25 367 + 24 649 = 76 012 — совпало.
